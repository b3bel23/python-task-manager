# ✅ Python Task Manager

Sistema de gerenciamento de tarefas desenvolvido em Python com interface interativa no terminal.

O projeto foi criado com o objetivo de praticar conceitos fundamentais de programação, modularização, manipulação de estruturas de dados e organização de código em Python.

---

## 📌 Sobre o projeto

O sistema permite o gerenciamento simples de tarefas, incluindo:

* Criação de tarefas
* Listagem de tarefas pendentes
* Marcação de tarefas como concluídas
* Remoção de tarefas

O projeto foi desenvolvido como atividade acadêmica da disciplina de **Fundamentos de Programação em Python**.
